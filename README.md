# Парсер для сбора данных с Wildberries

Парсер разработан с использованием playwright. Код выполняется асинхронно. Запускается несколько асинхронных задач, каждая из которых берёт ссылки для парсинга из общей очереди.

Реализована обработка таймаутов, повторные попытки загрузить и распарсить страницу, а также имитация действий пользователй (скроллинг и движение мыши) 

Используются прокси. Для каждого прокси создаётся отдельный контекст браузера. В рамках одного контекста запускается несколько страниц. Количество контекстов и страниц можно задать в параметрах


### Этапы работы скрипта:
1. Собирает ссылки на товары со всех страниц каталога
2. Отсеивает дублирующиеся ссылки
3. Проходит по всем страницам товаров и парсит каждую
4. Формирует DataFrame, производит фильтрацию и записывает в Excel


## Запуск
Для запуска необходимо в корне проекта выполнить команду
```shell
docker compose up -d
```
При необходимости перед запуском можно изменить конфигурации в `config.json`

## Конфигурации 

В файле `config.json` можно настроить следующие параметры

### Общие параметры
`proxies` - прокси. Задаются в формате списка словарей:
```json
[
  {
    "server": "<ip>:<prot>",
    "username": "<username>",
    "password": "<password>"
  }
]
```
`query` - запрос, по которому будет происходить поиск

`page_num_start` - номер страницы каталога, с которой будет начинаться парсинг

`page_num_end` - номер страницы каталога, на которой закончится парсинг

`output_path` - путь для сохранение результатов парсинга (относительно корня проекта)

### Параметры фильтрации
`filtered_rating` - рейтинг

`filtered_price` - цена

`filtered_country` - страна производства

### Параметры парснга

`count_contexts` - количество одновременно (асинхронно) запускаемых контекстов браузера

`pages_per_context` - количество страниц, которые будут параллельно открываться в рамках одного контекста


## Архитектура

### main.py
Точка входа, создаёт браузер в headless режиме и запускает процесс парсинга

### catalog_tasks.py 
`run_catalog_parsing_tasks` - метод создаёт асинхронную очередь со ссылками на страницы каталогов, создаёт контекст браузера и `pages_per_context` задач для этого контекста, затем запускает задачи. Дожидается из завершения и возвращает список ссылок на товары

`catalog_page_parsing_task` - метод берёт из очереди очередную ссылку на страницу каталога и запускает парсинг. Обрабатывает таймауты и ошибки. В случае таймаута, кладёт ссылку обратно в очередь, чтобы выполнить её в будущем

`parse_catalog_page` - метод парсит одну страницу каталога. Эмулирует скроллинг страницы до низа. Делает паузы, чтобы карточки товаров успели прогрузиться. Возвращает список ссылок на товары

### product_tasks.py
`run_product_parsing_tasks` - метод создаёт асинхронную очередь со ссылками на страницы товаров, создаёт заданное количество (`count_contexts`) контекстов браузера и `pages_per_context` задач для каждого контекста, затем запускает задачи. Дожидается их завершения и возвращает список с результатами

`product_parsing_task` - метод берёт из очереди очередную ссылку на страницу товара и запускает парсинг. Обрабатывает таймауты и ошибки. В случае таймаута при загрузке страницы, кладёт ссылку обратно в очередь, чтобы выполнить её в будущем. В случае таймаутов при ожидании загрузки отдельных элементов страниц, совершает 2 дополнительных попытки спарсить страницу. Если один из элементов всё же не удалось получить, данные товара сохраняются без него.

### parse_product.py

Модуль занимается парсингом страницы товара.
Для каждого поля (название, описание, цена и т.д) реализован отдельный метод.
Каждый метод возвращает результат парсинга и булево значение. False возвращает в том случае, если произошёл таймаут при попытке получить DOM-элемент. В таком случае страницу будет загружена заново

### context_manager.py

Занимается созданием контекстов браузера. Каждому контексту назначает отдельный прокси

### export_data.py

Формирует DataFrame из полученного списка словарей с данными о товарах. Производит фильтрацию и записывает в Excel

### config.py

Считывает значения параметров из конфигурационного файла
